# Security policy

## Scope

NetGuard is a defensive research prototype, not a production security control.
Reports can contain network identifiers and traffic metadata; operators are
responsible for protecting those files and analyzing only traffic they are
authorized to inspect.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting or Security Advisory
workflow for this repository. Do not publish exploit details, sensitive packet
captures, credentials, or personal network data in a public issue.

Include the affected version, a minimal reproduction, expected behavior,
observed behavior, and potential impact. Reports involving unauthorized access
to third-party systems are outside the project's intended use.
